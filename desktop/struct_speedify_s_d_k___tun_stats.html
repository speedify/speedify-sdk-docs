◆ segmentationOffloadActive

bool SpeedifySDK_TunStats::segmentationOffloadActive

Whether the TUN is currently exchanging super-packets with the kernel.

The state, as opposed to the segmentationOffload setting, which is only the request. False while the setting is on means it was asked for and did not take: see segmentationOffloadUnavailable and segmentationOffloadConfirmed for which half failed. The counters below cannot answer this – an offload that never applied and one that applied and found nothing to merge both read as zero.

Since
17.3
