Speedify SDK for Android 0.0.0.1/ Guides/ Prerequisites

Before you write any code, make sure the two things below are in place. Both are common first-time stumbling blocks: the first will make the app fail to connect at runtime, the second will make it fail to build.

Backend Authorization (required)

Apps built on the Speedify SDK must be authorized by Connectify before they can reach the Speedify cloud backend. Authorization is keyed on your app's package name + signing-certificate hash. Until the package/certificate you are building with has been authorized, login and connect calls will fail (reported via OnLoginError / OnConnectError) even though the app installs and runs normally.

Note that debug and release builds typically use different signing certificates — authorize both.

See SDK Authorization for how to obtain your certificate hash and request authorization.

Supported Android Versions

  • minSdk 28 (Android 9) or higher.
  • compileSdk / targetSdk 37 (Android 17) or higher. The .aar is built against API 37 and its AAR metadata will fail the build if you compile against an older API:
  Dependency ':speedifysdk' requires libraries and applications that depend on it to
  compile against version 37 or later of the Android APIs.

Build Environment

The SDK is built and published with the toolchain below. Use a compatible one in your app:

ToolVersion
Android Gradle Plugin9.2.0
Gradle9.5.1
Kotlin2.2.10
JDK17

IMPORTANT : As of AGP 9, the Android Gradle Plugin provides built-in Kotlin support. Do not also apply the standalone org.jetbrains.kotlin.android plugin — doing so fails the build with Cannot add extension with name 'kotlin'. Apply only the Android plugin (plus, if you use Jetpack Compose, the Compose compiler plugin):

  // build.gradle (app) — Groovy DSL
  plugins {
    id 'com.android.application'
    // Kotlin compilation is provided by AGP's built-in Kotlin support.
    // Only add this if you use Jetpack Compose:
    id 'org.jetbrains.kotlin.plugin.compose' version '2.2.10'
  }

If you use Jetpack Compose, the Compose compiler plugin version must match the Kotlin version that AGP bundles (2.2.10). Set your Kotlin/Java target via compileOptions; AGP's built-in Kotlin aligns the Kotlin jvmTarget to it:

  android {
    compileSdk 37
    defaultConfig { minSdk 28 }
    compileOptions {
      sourceCompatibility JavaVersion.VERSION_17
      targetCompatibility JavaVersion.VERSION_17
    }
  }

Once the above are in place, continue with the Integration Guide and Initializing the SDK.
