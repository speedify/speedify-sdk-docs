Speedify SDK for Android 0.0.0.1/ Guides/ Permissions

Required Permissions

  • INTERNET
    • Talk to speed servers on the internet
  • FOREGROUND_SERVICE
    • Ability to run VPN service in background
  • ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE, CHANGE_NETWORK_STATE
    • Check and control network adapter state
  • FOREGROUND_SERVICE_SYSTEM_EXEMPTED
    • Ability to run VPN service in background as of Android U

Optional Permissions

  • RECEIVE_BOOT_COMPLETED
    • Automatic reconnect after boot
  • QUERY_ALL_PACKAGES
    • Better Streaming mode performance, Allow apps that use P2P for legal purposes to stay on normal servers
  • VIBRATE
    • Default foreground notification will vibrate when entering kill switch mode
  • CHANGE_WIFI_MULTICAST_STATE
    • Required for network sharing
  • POST_NOTIFICATIONS
    • Required to see the foreground notification on Android T+
  • ACCESS_LOCAL_NETWORK
    • Required for Pair & Share discovery on Android 17+

Runtime Permissions

Most of the permissions above are install-time and merged in from the SDK's .aar manifest. A few must be requested at runtime:

  • POST_NOTIFICATIONS — request on Android 13+ (T) so the foreground service notification can be shown. See Service Notification for a request example.
  • ACCESS_LOCAL_NETWORK — request on Android 17+ for network sharing discovery. If discovery is blocked because it has not been granted, OnNetworkSharingLocalNetworkBlocked fires — request the permission in response.

VPN consent is handled separately (not a normal runtime permission): call initializeVPNPermission to show the system VPN dialog; the result is reported via OnVPNPermissionResult. See Initializing the SDK.
